# E2E 告知类信件回信失败：组织不存在

- 时间：2026-10-21 23:28
- Agent：assistant

## 现象

收到 E2E 测试信 `e2enormal0002`（寄件人「成员 #2」，主题「E2E普通信」，正文标注告知类、无需排期）。
执行 `mindx mail reply e2enormal0002 "..."` 报错：

```
rpc error -32603: 请求失败（HTTP 404）：{"error":{"code":"not_found","message":"组织不存在"}}
```

## 定位

`mindx mail inbox` 列出两封信（e2edeadline01、e2enormal0002），「回复指向」列均为 `—`。
即这两封信没有携带回复路由（无来源组织/回信地址），mail reply 按路由查组织时查不到，404。

## 结论

- 本机直投的 E2E 测试信不带回复通道，回信必然失败，不是本机配置问题。
- 后续遇到「回复指向 = —」的信件，不必反复尝试 reply，直接向用户说明该信无回信通道即可。
- 若 E2E 用例本意是验证回信链路，用例构造侧需补上回复指向（寄件组织需在服务端存在）。
