# Harness 优劣的关键指标

- 速度 - 天下武功唯快不破，Harness 的输出速度约等于模型的输出速度这才算快；
- 让模型变得更聪明 —— 让模型能工作是基操，而只是如此模型会变蠢。让模型能聪明地工作才是 Harness 的根本职责，只有能让模型在思考过程中持续“反省”的才能让模型变得聪明；
- 省钱 - 什么都塞进上下文自然能运行，将每一次请求的输入输出的Tokens都压死在底板上，那才是好Harness
- 摆脱金鱼一样的记忆 - Harness 没有记忆那就是人得了间歇性失忆症一样，什么你都得跟他重说一次；
- 会沉淀知识 - 这是超维指标，会回答，会干活，会思考算不了什么，能将成果自动积累那才是顶级Harness;
- 会进化 ？ - 能拓展的知识结构，能将沉淀的知识进一步拓展延伸，谁不喜欢自己家有个爱学习的小助手 ?
- 能大也能小 - 能开大卡车上大模型，也能飙小摩托，不论模型大小一样能跑；
