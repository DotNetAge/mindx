# 行业界面映射（预判参考）

用途：预判时按用户/项目行业查高频界面类型，校准功能清单与承载选择，避免发明生僻形态。**遇陌生行业或映射覆盖不了时，先上网搜罗该行业当下主流界面形态，把结论蒸馏回本文件并标注来源与日期**（外搜是兜底，搜到即沉淀）。

界面语汇统一用通用形态名：清单、看板、日历/时间线、表单、表格、详情页、仪表板、对话窗。

## 行业按用户密度排序（电脑操作依赖度 × 使用频次，2026-10-13 外搜蒸馏）

排序依据是**对电脑操作的依赖**（日均生产力应用时长、行业电脑使用度梯队、办公软件深度工作统计），不是对 AI 的依赖。行业范围不大，按"谁整天在电脑上干活、最可能大量使用本生态"排序。依据（2026-10-13 检索）：软件与信息技术日均生产力应用时长居各行业之首（5 小时 26 分，IDE 与代码评审为高频应用）；信息技术、金融、数据处理、科学研究为电脑使用度最高梯队；文档编辑器占远程知识工作深度工时首位（36.8%）。

## 1. 软件与信息技术

依赖依据：日均生产力应用时长全行业之首（5 小时 26 分），IDE 与代码评审工具为高频应用——全天候电脑操作。

| 迭代进度仪表板 | L1（scene-project） | 里程碑裁决 |
| 提交/构建时间线 | L1 | — |

## 维护约定

- 新行业条目：外搜结论按上表四列蒸馏，标注依赖依据与检索日期；排序只看**电脑操作依赖**（时长统计、使用度梯队），不混入 AI 使用类指标
- 与 templates/ 的关系：templates 是具体场景的完整方案，本文件是行业级界面语汇校准；冲突时以模板为准并回改本文件
- 未列出的行业属低电脑依赖或用户密度低，预判命中时先外搜确认是否值得建条目，再决定是否立项
