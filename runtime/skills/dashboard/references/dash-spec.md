# .dash 文件格式规范（dash-spec）

仪表板单文件格式的完整定义。手写 `.dash`、设计新控件或调试解析问题前必读；用脚本生成时本规范帮你判断 spec 能力边界。

## 总模型

一个 `.dash` 文件 = **布局 + 共享样式 + 全部卡片内容**，自包含，无外部数据文件。

- 每张 `<card>` 的内容被宿主放入**独立 iframe 文档**渲染（卡与卡互不可见，类名冲突无所谓）。
- `<board>` 是根元素，承载全局属性与 board 级共享样式。
- 卡内是**自由 HTML**（`.dash` 方言本身只有 board/card 两个元素，控件全靠 HTML + CSS 实现，标准控件骨架见 `card-cookbook.md`）。

## 文档结构

```html
<board name="显示名" gap="12" class="板级类名">
  <style>
    /* board 级共享样式：注入每张卡文档的 head */
    .stat .n { font: var(--mx-font-title); }
  </style>
  <card id="open" class="stat" span="6" title="待处理">
    <div class="n">11</div><div class="d">含 2 个 P1</div>
  </card>
  <!-- 更多 card … -->
</board>
```

- `<board>` 的直接子元素：至多一个 `<style>` + 若干 `<card>`。
- **卡内禁止再出现 `<board>` / `<card>` 标签**（破坏布局解析）。
- **不要写 `<html>/<head>/<body>`**——卡内 HTML 原样放入独立 iframe 文档，宿主负责文档骨架。

## 元素与属性定义

### `<board>`

| 属性   | 格式         | 缺省 | 约束与语义                                                                       |
| ------ | ------------ | ---- | -------------------------------------------------------------------------------- |
| `name` | 任意字符串   | 文件名 | 仪表板显示名（面板头部与侧栏清单标题）。取业务名，不要复读文件名                 |
| `gap`  | 整数 px（0..48） | 12   | 卡片列间距                                                                       |
| `class` | 空白分隔类名 | —    | 注入**每张卡**的文档 body，配合 board 级 `<style>` 一次作用全部卡                 |

`<style>` 子元素：CSS 原文，作为 **board 级共享样式**注入每张卡的文档 head；卡内自带 `<style>` 位于 body、加载顺序靠后，可覆盖 board 级同名规则。同款部件的公共样式必须写在这里，卡内只留差异。

### `<card>`

| 属性   | 格式             | 缺省 | 约束与语义                                                              |
| ------ | ---------------- | ---- | ----------------------------------------------------------------------- |
| `id`   | 字符串，board 内唯一 | —    | 宿主用它把卡内上报的高度对应回这张卡。**同名 id 会导致高度回报错乱**。取语义短名 |
| `span` | 整数 1..24       | 6    | 24 栏栅格占几栏。6=四分之一行、8=三分之一行、12=半宽、16=三分之二行、24=整行 |
| `h`    | 整数 px          | 120  | **初始**占位高度，实际高度自动跟随内容（内置高度桥）。图表/架构图卡建议显式设 h 给稳定初值（240 常用） |
| `class` | 空白分隔类名     | —    | 注入**该卡**文档 body（与 board class 合并），被 board 级 `<style>` 选择 |
| `title` | 字符串，可选     | —    | 卡片头部小标题（宿主渲染）。纯装饰卡可省                                 |

卡内可再写 `<style>`（卡级私有样式，只作用本卡）。

## 版式系统

- 栅格 24 栏。一行内多卡 span 之和 ≤ 24，超出换行。
- 一屏讲完核心信息：stat 概览行（4~5 张 × span 6）+ 主部件大卡（span 12..24）是常见骨架，场景化版式见各 `scene-*.md`。

## 解析行为

- 解析按 **HTML 宽容处理**：未闭合标签、裸 `&`、属性不引号都不炸。
- **同名 id 不报错但会破坏高度回报**——必须唯一。
- 卡内脚本 `<script>` 允许执行；运行在隔离沙箱，**无同源权限**（读不到父页面/本地文件/localStorage）；外部 CDN（ECharts 等）可用。

## 卡内运行环境（宿主注入契约）

| 项        | 契约                                                                 |
| --------- | -------------------------------------------------------------------- |
| 字体      | 系统栈、14px、行高 1.5                                               |
| 背景      | 透明（宿主卡片自带底色与圆角）                                       |
| 设计 token | 宿主注入 UIKit `--mx-*` 语义 token 全集，随主题切换自动刷新——写样式只用 token，**禁止写死色值**（详见 `design-spec.md`） |
| 高度      | 卡高自动跟随内容（高度桥），`h` 属性只提供初始占位                   |

## 落盘协议

- 约定落点：`.agents/dashboards/<名字>.dash`（项目内相对路径）——默认写这里。
- **发现规则**：宿主会扫描当前项目目录内全部 `.dash` 文件（递归，自动跳过
  node_modules/.git 等依赖与构建目录），不限于约定落点——写在其他业务目录
  （如 `docs/`、`reports/`）的 `.dash` 同样进入侧栏。
- 单文件即生效，用户端自动刷新，无需用户操作。
- 更新 = 重写该文件（只需改受影响卡片的标记，其余保持原样）。
