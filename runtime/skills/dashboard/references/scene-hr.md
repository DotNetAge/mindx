# 场景指引：人力资源仪表板

通用规范（工作流程、文件协议、设计规范、红线）见技能主文件 SKILL.md，本文只补本场景约定。

## 这个仪表板给谁看

HR 与团队负责人。他们关心：**人数结构、人员流动（入/离）、招聘进展、成员当前状态**。涉及真实姓名与隐私时只呈现用户明确提供的字段，绝不推测补全。

## 布局设计语言

常见版式起点：**概览行 + 双列中段 + 通栏底部**。

1. **顶部概览行**：团队总人数 / 本月入职 / 本月离职 / 在招岗位（4 张 stat × span 6）——人数结构一屏定调。
2. **中部左右双列**：左「部门人数分布」（水平条形，结构视角）｜右「招聘漏斗」（流程视角）。
3. **底部通栏**：成员卡片墙（头像 + 姓名 + 角色 + 状态点）——落到具体的人。

- **变体引导**：招聘季对话突出漏斗（漏斗提到首屏并加宽）；组织调整期突出部门分布（加第二维度，如编制 vs 在岗）；人数多的团队成员墙按部门分组或只放负责人层。

## 部件内容引导

| 部件          | 显示什么                     | 注意什么                                                                 |
| --------------- | ------------------------------ | -------------------------------------------------------------------------- |
| 团队概览 stat | 总人数、入职、离职、在招岗位 | 入职用成功色、离职用警示色；副说明写口径（「5 个部门」「2 个岗位急招」） |
| 部门人数分布  | 部门名、人数、占比条         | 条宽 = 人数 ÷ 最大部门；行数 3~8                                         |
| 招聘漏斗      | 阶段名、各段人数             | 末段（入职）换成功色；窄段保 min-width 可读                              |
| 成员卡片墙    | 头像圆点、姓名、角色、状态点 | 状态：绿=在岗、橙=忙碌、灰=休假/离线；头像底色轮换、字取姓氏             |

## 语义色映射（全板一致）

通用纪律见 SKILL.md「设计规范」。本场景语义色映射：

| 语义               | token                                                            |
| -------------------- | ------------------------------------------------------------------ |
| 在岗 / 已入职      | `var(--mx-success)`                                              |
| 忙碌 / 超负载      | `var(--mx-warning)`                                              |
| 休假 / 离线 / 空缺 | 30% 透明中性点（`color-mix(in currentColor, 30%, transparent)`） |
| 漏斗主色           | `var(--mx-accent)`，末段（转化完成）`var(--mx-success)`          |
| 部门 / 序列分布条  | accent / success / warning / business 轮换                       |

## 取数来源

用户提供的团队文件、对话上下文；内联静态值，绝不编造人员与数字。
