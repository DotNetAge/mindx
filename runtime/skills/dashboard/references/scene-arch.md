# 场景指引：架构仪表板

通用规范（工作流程、文件协议、设计规范、红线）见技能主文件 SKILL.md，本文只补本场景约定。

## 这个仪表板给谁看

架构师与研发负责人。他们关心：**系统全貌（模块怎么连）、服务健康（现在活着吗）、构成（技术栈分布）、职责边界（谁负责什么）**。架构图是视觉主体，清单与分布是辅助。

## 架构图两条路线

| 路线            | 适用                                             | 做法                                                 |
| ----------------- | -------------------------------------------------- | ------------------------------------------------------ |
| A. Archify 植入 | 完整交互架构图（pan/zoom/搜索/主题），系统较复杂 | 用 archify 技能生成 standalone HTML，整段植入大卡    |
| B. 手写轻量拓扑 | 小系统速览、分层结构说明                         | 按「部件内容引导」的分层拓扑手写，或查 card-cookbook |

### 路线 A：Archify 产物植入流程

1. 按 `archify` 技能生成架构图 standalone HTML（如 `architecture` 类型），先落盘为独立产物文件（不要直接丢进仪表板文件）。
2. 产物 HTML **整段粘进 `<card>` 即可**：仪表板解析器会剥离 `<html>/<head>/<body>` 包裹标签，`<style>/<script>/<link>` 与 body 内容原样保留（已实证）。也可用脚本：raw 卡的 `html_file` 参数直接指向产物文件（new_board.py）。
3. 卡属性：`span="24"`，`h` 给足初值（架构图通常 420~560，如 `h="520"`）。
4. 产物自带主题切换、pan/zoom、搜索等 Viewer 交互，沙箱内正常可用。
5. **体量判断**：产物超过约 500KB 不要整卡植入——改路线 B 手写拓扑，或只摘产物核心 SVG 片段 + 关联样式。

## 布局设计语言

常见版式起点：**主体大通栏 + 辅助行**。

1. **首屏主体**：架构图大通栏（span 24，路线 A 植入或路线 B 手写）——全貌先行。
2. **第二行**：健康度 stat（服务总数 / 运行中 / 告警 / 本周变更，4 张 × span 6）——状态一眼可见。
3. **通栏**：服务清单表（服务 / 职责 / 技术栈 / 端口 / 状态）——职责与状态逐条可查。
4. **底部双列**（可选）：技术栈分布条 ｜ 核心调用链速览（手写分层拓扑）。

- **变体引导**：对话聚焦某个域时，架构图换成该域的局部拓扑放大；告警处理场景把告警 stat 提前并附告警明细卡。

## 部件内容引导

| 部件         | 显示什么                         | 注意什么                                                |
| -------------- | ---------------------------------- | --------------------------------------------------------- |
| 架构图植入卡 | Archify 产物（或手写拓扑）       | span 24 + h 420~560；放 board 首位                      |
| 健康度 stat  | 服务数、运行中、告警、变更       | 告警非零用警示色；副说明写具体原因（「网关 P99 偏高」） |
| 服务清单表   | 服务名、职责、技术栈、端口、状态 | 端口/路径等宽字体；状态点：绿正常/橙告警/红维护中或停用 |
| 技术栈分布   | 语言/框架 + 服务数条形           | 条宽 = 该项 ÷ 最大项                                    |
| 手写依赖速览 | 分层节点 + 层间调用标注          | 3~5 层、每层 1~3 节点；更复杂一律走 Archify             |

## 语义色映射（全板一致）

通用纪律见 SKILL.md「设计规范」。本场景语义色映射：

| 语义               | token                            |
| -------------------- | ---------------------------------- |
| 运行正常           | `var(--mx-success)`              |
| 告警 / 降级        | `var(--mx-warning)`              |
| 故障 / 不可用      | `var(--mx-danger)`               |
| 变更 / 发布 / 强调 | `var(--mx-accent)`               |
| 技术栈分布条       | accent / business / warning 轮换 |

注：Archify 产物若自带配色，植入时在产物 `<style>` 后追加一段 board 级覆盖（把产物主色改绑 token），避免与主题割裂。

## 取数来源

工作区架构文档、服务目录、对话上下文；服务名/端口/状态必须真实，没有数据就留卡位请用户补充，绝不编造服务。stat/bars/table 全是标准部件 → 用脚本 new_board.py（架构图植入用 raw 卡 + `html_file` 指向产物；手写拓扑查 card-cookbook）。
