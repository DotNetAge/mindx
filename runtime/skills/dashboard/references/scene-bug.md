# 场景指引：BUG 管理仪表板

通用规范（工作流程、文件协议、设计规范、红线）见技能主文件 SKILL.md，本文只补本场景约定。

## 这个仪表板给谁看

QA 与研发负责人。他们关心：**当前存量（还有多少）、严重构成（危险的在哪）、趋势（新增快还是修复快）、卡在哪（流转阻塞）**。仪表板按「结论 → 结构 → 流向 → 明细」组织视线。

## 布局设计语言

常见版式起点：**概览行 + 双列中段 + 双通栏底部**。

1. **顶部概览行**：本周新增 / 待处理 / 修复中 / 已修复（4 张 stat × span 6）——存量定调。
2. **中部左右双列**：左「七日趋势」（ECharts 双线：新增 vs 修复，趋势视角）｜右「严重级分布」（水平条形，风险构成视角）。
3. **通栏一**：缺陷流转列（待确认 → 修复中 → 待回归 → 已关闭）——每个缺陷现在卡在哪。
4. **通栏二**：P0/P1 明细表——危险的缺陷逐条可查。

- **变体引导**：发布前冲刺把「流转列」提前到概览行下方；回归期把「待回归」计数做成独立 stat；缺陷量大时明细表只留 TopN 并注明「完整清单见文件」。

## 部件内容引导

| 部件          | 显示什么                                 | 注意什么                                                                      |
| --------------- | ------------------------------------------ | ------------------------------------------------------------------------------- |
| 缺陷概览 stat | 新增、待处理、修复中、已修复             | 新增上升用警示色；副说明写口径（「含 1 个 P0」「回归通过 21」）               |
| 七日趋势      | 新增 vs 修复双线，日期轴                 | 修复线长期低于新增线 = 积压在涨，需在结论里点出；轴文字 currentColor 跟随主题 |
| 严重级分布    | P0..P3 人数条                            | 语义色全板固定：P0 红 / P1 橙 / P2 蓝 / P3 绿                                 |
| 缺陷流转列    | 列名 + 计数 + 任务卡（标题/级别/负责人） | 列数 3~5；每列计数用强调色                                                    |
| 缺陷明细表    | 编号、标题、级别、负责人、状态           | 编号等宽字体；只放重点子集（P0/P1 或 TopN）                                   |

## 语义色映射（全板一致）

通用纪律见 SKILL.md「设计规范」。本场景语义色映射（严重级全板统一，不得换色）：

| 语义            | token                                            |
| ----------------- | -------------------------------------------------- |
| P0              | `var(--mx-danger)`                               |
| P1              | `var(--mx-warning)`                              |
| P2              | `var(--mx-business)`                             |
| P3              | `var(--mx-success)`                              |
| 新增上升 / 恶化 | `var(--mx-danger)`；收敛下降 `var(--mx-success)` |
| 修复中          | `var(--mx-warning)`                              |

## 取数来源

缺陷清单文件（issues/*.md、bugs.csv 等）、对话上下文；内联静态值，绝不编造编号与人名；流转列与表格数据同源一致。ECharts 趋势卡用 raw 卡手写（参考范例）。
