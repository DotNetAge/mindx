# 参考实现

这里收录的是"已经跑通过的一种做法"，用来给 Agent 做参照——**不是接口规范**。换模型、换美术风格时，参数必须按新模型重新推，照抄数值会得到穿模、露腔、漂件。

## 参考实现 A：程序化 rig（`app/src/pet/cow.ts`）

用于"只有静态模型、没有骨骼动画、要会呼吸转头摸头"的形态。做法：把 mesh 按包围盒分件，每个件 reparent 到一个位于关节根部的 Group，之后旋转 Group 就是绕关节的纯刚体旋转——零顶点形变，也不会拉出缝隙。

### 模型前提（不满足就换做法）

- 部件已拆成独立 mesh，节点无变换，顶点直接落在模型空间。
- 每个部件已闭合收口，不需要运行时补面。
- 部件判据可只用包围盒得出（即 mesh 名不可靠，`meshes[i]` 这种名字是常态）。

### 分件判据（牛牛实测值，对应模型 y∈0..1、x∈-0.475..0.5、z∈±0.475）

| 部件 | 判据 | 说明 |
| ---- | ---- | ---- |
| 头 | `maxY > 0.55` | 该组中顶点最多的一件当刚体，用它的包围盒中心作旋转支点 |
| 耳 | 头的子集中 `max(|minZ|, |maxZ|) > 0.34` | 明显超出头球半径 0.312 |
| 眼 | 头中：`centerX > 0.05`、`centerY ∈ (0.6, 0.75)`、`max(|minZ|,|maxZ|) < 0.2` | 只有一对眼球命中；耳与角中心 X 为负 |
| 手/前肢 | `minY > 0.19` 且 `maxY < 0.4` 且 `maxX < 0.25` | 笔记本与脚都不满足 |
| 尾 | `maxX < -0.3` | 整块在后方下方 |

### pivot 补偿（关键，做错就整体位移）

把一个或若干 mesh 挂到以 `root` 为原点的新 Group：

```
g.position = root - parentOrigin        // 相对父级原点
for each mesh: mesh.position = -root    // 子件补偿，保证静止时世界坐标不变
```

父级静止时，pivot 的模型空间原点恰为 `root`，mesh 顶点坐标不变。验收方法：静止帧逐 mesh 世界坐标与原始模型一致。

### 动作参数

| 动作 | 参数 |
| ---- | ---- |
| 视线跟随 | `yawMax 1.3`（±74°）、`pitchMax 0.65`（±37°）、`rollMax 0.06`、缓动系数 `1.5` |
| 忙碌 | 鼠标俯仰权重压到 30%，另叠 `busyLookDown 0.34`（≈19.5°）固定低头 |
| 打字 | 手速 `20.1 rad/s`（每只手 3.2 次/秒，交替 6.4 键/秒）、抬幅 `0.16` |
| 摸头 | 耳抖 `17`、尾摆 `12.5` |
| 疑问 | 耳上翘 `0.34`、耳抖 `0.06 @ 7.2`、头偏 `-0.3`、滚转 `0.34`、俯仰 `-0.14`、尾摆 `0.22 @ 2.4`、持续 `4.2s`，到期回落到进入前的持续态；疑问期间 `questionAmt` 压掉忙碌分量（手部敲击与 `busyLookDown` 同步衰减），否则「边打字边歪 10°」肉眼会被打字动作吃掉 |
| 眨眼 | 周期 `10s`、单次 `0.16s`、纵向压到 `0.92`，露出头贴图的浅色眼底形成眨眼 |

### 三个已踩过的坑

1. **耳根埋深**：耳根取包围盒靠头的内侧再往头里埋 `0.05`。埋浅了 + 抬得高，从背面会看见耳根的白色空腔。
2. **耳片摆幅上限**：超过 `0.42rad` 碗状耳片从背面露白腔；牛牛疑问用 `0.34` 起翘（含 `0.06` 抖动已贴近上限，再加大需逐帧从背侧复核）。
3. **尾球漂离**：尾摆到 `0.62rad` 时尾球会脱离身体，牛牛用 `12.5 rad/s` 频率但幅度受限。

### 验收（可复核）

- 静止帧零位移（逐 mesh 世界坐标与原始模型一致）。
- 头转到声明上限，头身接缝无裂缝。
- 摸头时耳抖与尾摆不穿模。
- `busy` 时视线落在前肢操作区（例如笔记本位置），不左右乱看。
- 同构模型（同部件数、同相对位置）复用同一份参数仍能跑。

## 参考实现 B：sprite 图集

一维或网格图集，等分切帧，透明底。低帧率（8–12）足够；关键是帧与帧之间形象不能跳位，否则播放时看起来在闪。

## 参考实现 C：gltf-clip

Blender 导出 glTF 2.0，勾 Animation + Embedded 贴图；clip 名与清单逐字一致。常见错：只勾 Pose 不勾 Action（clip 为空）、贴图外置（换机丢图）、朝向不是 `+X`（用 `yaw` 修）。

## 使用纪律

- 抄数值前先确认模型的坐标尺度与朝向一致；不一致时把所有判据按包围盒比例换算，不要直接套绝对值。
- 参考实现里的"实测"数值只对该模型成立，换模型要重新跑 `verify_buddy.py --inspect` 复核。
