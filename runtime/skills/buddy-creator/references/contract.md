# Buddy 契约细则

方法清单见 SKILL.md；此处只给正文未覆盖的时序、坐标与边界。

## 生命周期

```
壳启动           mount(container, ctx)       → 组件自建 DOM/WebGL 上下文
光标移动         lookat(x, y)                → 每 50ms 一次，连续调用
工作台事件       notify(kind) / question()   → 瞬发
                 jump()                      → 瞬发（任务完成时与 notify 二选一，见下）
交互             play() / drag(on)           → 摸头 / 拖拽
会话状态         busy(on)                    → 进入与退出各调一次
切换/关闭        dispose()                   → 释放定时器、监听、GPU 资源
```

- `mount` 抛错或超 3 s 未 resolve，壳回退内置默认宠物，本次会话不再尝试该组件。
- `dispose` 之后不得再有任何回调；壳在 `dispose` 返回后立即销毁容器，迟到的 `requestAnimationFrame` 写 DOM 会抛错，组件须在 `dispose` 内取消。
- 同一组件实例在宠物窗整个生命周期内只 `mount` 一次；壳不做热重载，改动后重启壳。

## 坐标系

- `lookat(x, y)`：`x` 右正左负，`y` 下正上负，范围 `-1..1`，对应宠物窗可视区。壳不提供像素坐标。
- 组件内部自行把归一化值转成角度/位移；`lookat` 只表示"视线想去哪"，不代表已经转过去。
- 壳约每 50ms 送一次，组件须做插值（建议时间常数 0.15–0.2 s），直接赋值会抖。

## 并发与排队

- 瞬发动作（`notify` / `question` / `play` / `jump`）：壳维护 FIFO 队列，上限 3，超出丢最旧；同一时刻只有一个在播。
- 瞬发动作播放期间到达新动作，不打断当前，等当前结束（壳侧按 1.2 s 基线判定结束；组件若想自定义时长，通过 `buddy.json` 的 `durations` 声明，单位毫秒）。
- `busy(on)` 与 `drag(on)` 是状态，不排队，后到覆盖先到。
- `notify('complete')` 与 `jump()` 的关系：壳在任务完成时只调 `notify('complete')`；`jump()` 仅用于用户主动交互（例如点中宠物身体时的高兴反应）。组件若希望完成时跳一下，在 `notify('complete')` 内部实现，不要等壳额外调 `jump`。

## ctx 语义

- `ctx.assets` 形如 `mx-buddy://cow/`，末尾带斜杠；组件拼 `ctx.assets + 'cow.glb'`。
- `ctx.size` 是宠物区边长（逻辑 px，随 S/M/L 档位变化），不包含气泡条；组件按此值做等比布局，允许内部有留白。
- `ctx.theme` 在切换主题时不会二次通知；需要跟随主题的组件应在 `mount` 时读一次，或在自身 DOM 用 CSS 变量（壳在 `documentElement` 上挂 `data-theme`）。

## 缺省兜底的精确参数

组件不实现某方法时，壳执行下表的通用反应，参数固定，不得按组件调整：

| 方法            | 兜底动作                                     |
| --------------- | -------------------------------------------- |
| `notify(kind)`  | 容器整体 `translateY(-8px)` 后回落，300 ms   |
| `question()`    | 容器整体 `rotate(6deg)` 后回弹，400 ms       |
| `play()`        | 容器 `scaleY(0.92)` 后回弹，250 ms           |
| `jump()`        | 容器 `translateY(-12px)` 后回落，350 ms      |
| `busy(on)`      | 容器 `scale(0.98)` + 摆幅减半（壳侧持续态）  |
| `drag(on)`      | 跟手位移，松手 200 ms 回弹                   |
| `lookat(x, y)`  | 容器视差平移，幅度 `x*6px`、`y*4px`，线性插值 |

兜底只动容器变换，不触碰组件内部，因此与组件实现可以共存：组件写了动作，壳就不动容器。

## 错误约定

- 组件任意方法抛错：壳捕获、记一条日志、该方法视为未实现（后续同类调用直接走兜底），不卸载组件。
- `mount` 抛错：回退默认宠物，并把该组件在设置页标为"不可用"。
- 组件内 `console.warn` 会被壳转发到主进程日志，用于排查；`console.log` 在成品壳中丢弃，不要依赖它做状态传递。
