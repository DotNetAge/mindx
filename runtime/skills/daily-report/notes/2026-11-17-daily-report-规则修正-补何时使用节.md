## 2026-11-17 补「何时使用」节与不使用边界（workbuddy）

- 问题：结构缺失——skill-creator 骨架三段要求正文含「何时使用 / 决策路由 / 纪律边界」，本技能自建成起直接以「报告文件」开篇，正文里没有触发场景与边界声明；description 虽写了触发词，但执行者加载正文后看不到「什么时候不该用」，容易把提炼规则、跨项目盘点也接过来。
- 修正：补「何时使用」节——三条触发场景（要日报/复盘收尾落报告/汇总成员报告）+ 两条不使用边界（提炼规则与沉淀技能、跨项目盘点），边界用能力名表述而不指名同伴技能；原「硬约束」四条禁令按七项自检第 4 条改写为四条「现象→原因→动作」失败模式，信息量不变、格式合规。version 1.2.0 → 1.2.1。
- 验证：`mindx skill validate` 全绿（97 行、soft_rules 0）；正文四节标题依次为「何时使用 / 报告文件 / 报告结构 / 输入来源」。
