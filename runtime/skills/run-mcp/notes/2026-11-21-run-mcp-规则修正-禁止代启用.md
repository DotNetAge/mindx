## 2026-11-21 技能自动启用绕过用户授权（mainagent）

- 问题：指令冲突——1.1.0 的 run 在条目 disabled 时自动执行 enable，与「技能只能调用 enabled 服务、不得代用户启用」的约束冲突，会在用户不知情下改写 mcp.json 启用状态。
- 否决：保留 `--no-enable` 让自动启用变成可选——默认仍是自动启用，用户未显式拒绝就会被改动，否决。
- 修正：删除脚本里的 `auto_enable` 分支与 `--no-enable` 参数；disabled 一律返回 exit 8，输出里只给 `python3 scripts/mcp.py admin enable <name>` 作为用户确认后的手动动作。SKILL.md 1.1.0 → 1.2.0；references/commands.md 同步退出码与解析顺序。
- 验证：`run memory read_graph`（条目 disabled）→ exit 8、mcp list 中 memory 仍 enabled=false；由操作者手动 `admin enable memory` 后 `run memory read_graph` 正常返回 `{"entities":[],"relations":[]}`；再 `admin disable` 恢复，重跑 `run` 回到 exit 8。只读的 `run <server>`（列工具）不受影响。
