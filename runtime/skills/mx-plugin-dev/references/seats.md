# 席位映射表与问卷题库

选项的唯一合法来源：本表提炼自 mx-plugin-dev `references/contract.md` 八区契约与实证机制。组题时禁止映射表之外的"席位"。

## 席位映射表（用户意图 → 八区席位）

| 用户想做的事 | 席位 | 契约要点（组选项时用白话转述，勿贴 API） |
| --- | --- | --- |
| 左侧导航加一个分组入口（含菜单行） | Sidebar 分节 | 分节带标题与行列表；行点击切换主界面；折叠成 rail 时显示图标；行 id 必须对应 Content 条目 id |
| 主界面新增一个工作页 | Content 页 | 行点击后呈现的主内容区；页标题自动出现在顶部工具栏 |
| 选中对象的详情侧栏 | Detail 轨道 | 右侧滑出的详情面板（可多 tab）；内容页挂载时可自动打开 |
| 非阻塞通知（操作结果、状态变化提醒） | Overlay banner | 顶部堆叠通知条，不打断操作，自动有关闭钮 |
| 阻塞式确认/表单（危险操作、二次确认、多字段输入） | Overlay modal | 全屏遮罩对话框，同一时刻只存在一个；Esc 先关它再关设置面板 |
| 大面积工作面/沉浸式面板（向导、大批量表单、聚焦视图） | Sheet 全屏抽层 | 由下向上滑入覆盖整个界面，标题居中显示、右上角固有关闭钮；同一时刻只存在一个 |
| 不阻塞主界面的辅助小面板（迷你播放器、悬浮工具、小窗内容） | Floater 可拖动浮窗 | 无 titlebar，头部为模拟交通灯红灯（点击关闭）+ 标题；按住头部拖动；可同时开多个，点击置顶 |
| 顶部工具栏常驻操作 | Toolbar 席位 | 分左（leading）/右（trailing）两组；不放则不渲染 |
| 全局配置（用户可调的偏好） | Settings 页 + 行 | 设置面板里独立一页；配置行复用壳控件（开关/步进/下拉等） |
| 给别的插件提供数据或能力 | services 服务 | 跨插件共享 Pinia 状态本体；只 provide/use，禁止插件间 import |
| 侧栏顶部/底部固定按钮（新建、折叠等全局动作） | Sidebar Header / Footer | 固定区席位，不随内容滚动 |

## 轮 1 题库（必问，单次打包成 2-3 题）

1. **这个插件解决什么问题？**（开放题 + 2-4 个猜测性示例选项帮用户起步；用户回答后不得再猜，后续轮次以回答为准）
2. **用户在什么场景下用到它？**
   - 日常高频：作为工作台的一部分常驻使用
   - 偶发查看：需要时从导航进入看一眼
   - 事件驱动：平时无感，特定事件发生时弹通知
   - 配置一次：装好配置完就不再打开
3. **主交互形态是什么？**
   - 浏览为主（看内容、看状态）
   - 动作为主（点按钮执行操作）
   - 两者混合（浏览中穿插操作）

## 轮 2 题库（席位多选，按轮 1 裁剪）

**"需要哪些界面席位？"（多选）**——候选项按轮 1 答案裁剪组织：

- 事件驱动 → 候选：Overlay banner（通知）；Overlay modal（需要确认时）
- 浏览为主 → 候选：Sidebar 分节 + Content 页；Detail 轨道（要看详情时）
- 动作为主 → 候选：Toolbar 席位；Overlay modal（动作确认）
- 配置一次 / 有可调偏好 → 候选：Settings 页 + 行
- 需要全局快捷动作 → 候选：Sidebar Header / Footer
- 跨插件协作（提供或消费数据）→ 候选：services 服务

裁剪原则：用户答"事件驱动 + 无确认"就不出现 modal 选项；每题至多 4 个选项，超出拆两题。

## 轮 3 题库（交互编排，按轮 2 所选席位裁剪）

1. **行点击后的行为**（选了 Sidebar + Content 时问）：
   - 仅切换主页面
   - 切换主页面并自动打开详情侧栏（实证：Content 页 onMounted 调 Detail.show 即自动打开）
2. **通知与确认的边界**（选了 Overlay 时问）：哪些事件发 banner、哪些动作要 modal 确认（危险/不可逆操作必须 modal）。
3. **配置项清单**（选了 Settings 时问）：逐项收集配置名与取值形态（开关 / 数值步进 / 下拉枚举 / 文本）。
4. **导航排布**（选了 Sidebar 时问）：分节放在现有导航的哪个位置段（order 越小越靠前，缺省 100——给用户的是"靠前/居中/靠后"白话选项；换算成取值时守保留范围：预置插件落 1–1000 保留段，market 在线插件必须 ≥ 1001）。
5. **启停语义**：停用插件时应清理到什么程度（全部席位移除 + 配置保留，是缺省；问用户是否有例外）。

## 组题纪律

- 白话转述：题面向用户说"右侧详情面板"，不出现"Detail.show"；契约要点是 Agent 自己的判据。
- 单次问答至多 4 题；轮 2/3 可按答案合并轮次，但轮 1 与轮 4 不可省。
- 用户选择之间存在冲突时（如"配置一次"却选了 Sidebar 常驻入口）当场指出并让用户裁决，不自行取舍。
