## 2026-11-17 标题对齐骨架并补不使用边界（workbuddy）

- 问题：输出格式——skill-creator 骨架三段的首节固定为「何时使用」，本技能写作「何时用」，与体系内其它技能不一致；且只有正面场景、无「不使用」边界，单项目深挖与代码审查类请求可能被误解为本技能可接。
- 修正：标题改「何时使用」；补不使用一条（单项目深入分析、技术审查不属本技能，本技能只做概况盘点的呈现）；补三条失败模式（越界读源码、三处无资料硬写、混入专业判断）。version 1.1.0 → 1.1.1。
- 验证：`mindx skill validate` 全绿（52 行、soft_rules 0）。
