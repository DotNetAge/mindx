# Agent 排期回看间隔封顶

- 问题：用户实测发现 LLM 给 Agent 安排任务时按人的时间观排期——「几小时后再查」「明天再看」这类间隔。Agent 是程序，给 Agent 的任务除非需用户确认或用户明说为真人排期，一律马上开始；回看间隔应按预估执行时长封顶（半小时已是长活）。第四步 Cron 行原把「跨天等待」列为合法等待方式且未限定等的是谁，正是人的日程间隔的藏身处。
- 否决：不落在 team-design.md——第 5/11 条已把估算定档与派工章法指针指向本技能，再写即同义重复（三处收敛定案的既判）。
- 修正：第四步 Cron 行补约束——Cron 只等真人或外部事件，不用于等 Agent 干活；派给 Agent 的任务默认马上开始，回看与跟进间隔按预估执行时长封顶。同源洞察已先行落 assistant SOUL.md（排期不按人的钟）。version 0.8.3 → 0.9.0。
