## 2026-11-17 计划与执行结构拆分（glm）

- 问题：用户指出「做的是计划，关派发什么事」——第四步标题是分配排程（计划动作），正文却塞满派发机制，与 intro「本技能不做具体执行」直接矛盾；用户不首肯时正文细节引导 LLM 提前派发。根因是步骤职责越界（计划步预写执行动作），此前四轮句子级打补丁未定位到此结构级根因。
- 修正：价值链五步扩为六步——第四步只产出计划（任务清单+定档+分配+执行方式建议+排程，用户认可即生效，明写「本步只产出计划，不发生任何执行动作」）；执行动作独立为第五步「按计划执行」（0 档自己动手 / 1 档以上派对口负责人 / 派发方式判定 / 任务书 / 回写账本）；验收关账顺延为第六步，全部交叉引用同步（账本状态规则、一次性目标、每日例行）。intro 矛盾句改「第四步产出获批的计划，第五步才发生动作」。version 0.5.9 → 0.6.0。
