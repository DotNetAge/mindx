# ⚡ 触发方式详解

## 自动触发（意图匹配）

基于意图识别激活，不要求特定关键词。

### 构建意图方向（任一匹配）

| 意图方向 | 常见自然表达（非穷举） |
|:---|:---|
| 从零创建 | "帮我做一个 XX""设计一个 XX 专家""写一个 XX Agent""创建一个 XX 智能体" |
| 已有改进 | "优化这个 Agent""这个 prompt 质量怎么样""帮我强化一下这个角色""审查这个技能" |
| 人物复刻 | "蒸馏 XX""复刻 XX 的思维方式""做一个像 XX 一样思考的助手" |
| 质量评估 | "评估这个 Agent""这个 prompt 打几分""检查规则有没有冲突""验证一下这个技能" |
| 范式选择 | "我想要一个专家，但不知道用哪种方式""人物蒸馏和岗位型有什么区别" |

> **核心原则**：只要表达了"创造/改进/评估具有明确角色身份的 AI Agent"意图即触发。不要求精确词。

### 反例（不触发）

| 表达 | 原因 | 应走路径 |
|:---|:---|:---|
| "什么是 Agent？" | 纯概念问答，无构建意图 | 知识问答 |
| "帮我写一段 Prompt 模板" | 只有写作需求，无角色目标 | 通用写作 |
| "这个文件怎么打开？" | 与 Agent 设计无关 | 文件操作 |
| "帮我查一下今天的新闻" | 信息检索 | 搜索工具 |
| "我想了解 Prompt Engineering" | 学习需求，无具体构建目标 | 知识问答 |
| "有没有现成的代码审查 Agent？" | 寻找已有工具 | 推荐/搜索工具 |

### 灰区处理

| 灰区表达 | 处理方式 |
|:---|:---|
| "帮我改一下这段话让 Agent 更像律师" | 构建意图 + 角色目标 → 触发（靶向编辑） |
| "我需要一个能审查合同的，帮我看看怎么写 prompt" | 有角色目标意图模糊 → 追问："从零设计还是改进已有？" |
| "我想做一个聪明的助手" | 构建意图但角色模糊 → 追问："像某个岗位还是像某个人？" |
| "Agent 设计有什么最佳实践？" | 知识问答无构建目标 → 不触发，可询问"要不要实际做一个？" |

> 追问仅限 1 轮。1 轮后仍无法确定 → 按最常见意图（岗位型）启动，标注假设前提。

## 快捷命令（可选速记）

| 命令 | 等价自然语言 | 效果 |
|:---|:---|:---|
| `设计 [岗位名]` | "帮我设计一个 [岗位名] 专家" | 岗位型流水线 J1→J5 |
| `蒸馏 [人名]` | "复刻 [人名] 的思维方式和表达风格" | 人格蒸馏流程 |
| `优化 [角色名]` | "帮我优化 [角色名] 的 prompt" | 靶向编辑 |
| `评估 [角色名]` | "帮我评估 [角色名] 的质量" | 5 维质量评估 |

> 直接说"帮我做一个税务顾问"完全等同于 `设计 税务顾问`。

---

## 触发宽容度设计

```
用户输入
  ├─ 明显有构建意图 + 角色目标 → 立即激活，走范式路由
  ├─ 可能有构建意图但角色目标模糊 → 追问 1 个关键问题后激活
  ├─ 仅有构建意图无角色目标 → 追问 1 个澄清问题
  └─ 完全无构建意图 → 不触发
```

> 宁可误触发后优雅退出，也不漏触发让用户反复措辞。误触发→"这超出了我的设计范围，建议你[替代路径]"即可退出。
