# smoke_test.py — 离线自测脚本使用说明

对应源码:`scripts/api_client/smoke_test.py`。用于验证客户端包可导入、校验规则正确、日期转换与引导错误输出正常。**不访问真实服务**,可随时运行。

## 运行命令

```
python3 ./scripts/api_client/smoke_test.py
```

## 预期结果

全部用例输出 `[OK]`,最后一行:

```
全部冒烟用例通过。
```

覆盖用例:时间戳格式、日期转换、日期格式不合法、必填缺失、数量小于 1、手机号格式、状态枚举完整(含 8 个业务模块)、未登录访问引导(11 个业务模块 + 主数据查询 8 实体 + 仓库主仓)、非法/停用过滤字段拦截(业务模块与主数据实体)、find-for 权限校验、追踪命令缺参/未登录拦截(po-track/so-track)、主数据白名单放行(material supplier_name)与批量/BOM 缺参拦截、检查点结构(ok/guide 随判定切换)。

## 何时使用

- 客户端代码被修改后,确认没有破坏既有行为。
- 遇到"命令报错"时,先运行本脚本确认客户端本身健康,再排查参数或服务问题。
