# 质量门（Quality Gate）

候选技能落位前的评分与棘轮规则。内嵌自包含，不依赖外部优化技能。

## 铁律：确定性计算统一走 CLI / scripts/

SKILL.md 规范的机器校验唯一实现是 CLI：`mindx skill validate --path <技能目录>`（skillstore.CheckQuality，JSON 报告，退出码 0=通过 / 1=error）。skill-creator 审查步骤 B 与本质量门均调用它——禁止复写检查逻辑，防止实现漂移。

记忆治理专属的两个脚本仍是确定性计算的补充实现：

| 脚本 | 用途 | 调用 |
|---|---|---|
| `scripts/fapprox.py` | 记忆条目引用密度先验（主线二去存量排序） | `python3 {base_dir}/scripts/fapprox.py <agents_dir>` |
| `scripts/refcheck.py` | 引文连锁校验（[ref:ID] 断裂检测） | `python3 {base_dir}/scripts/refcheck.py <agents_dir>` |

禁止 LLM 心算替代；LLM 负责决定跑哪个、解读 verdict 与 reason。

## 五维评分（每维 0-10，总分 50）

| 维度 | 分值来源 | 评分要点 |
|---|---|---|
| 1. 触发准确性 | 确定性自查 | description 说明"何时使用"而非功能介绍；含明确触发词；≤1024 字符；name 小写连字符且与目录一致 |
| 2. 自包含 | 确定性自查 | 正文不依赖引用原始 memory/notes 文件；不出现"参见某条记忆"式表述；脱离原始对话也能执行 |
| 3. 具体性 | LLM 评 | 步骤带参数/格式/示例；无"适当处理""酌情"类软化词；脆弱操作有精确指令 |
| 4. 失败模式 | LLM 评 | 显式编码失败分支与 fallback（三段式：现象→原因→动作）；无失败分支该维 ≤3 分 |
| 5. 体积控制 | 确定性自查 | 正文 ≤150 行；只补执行者不知道的；重复描述已合并 |

判定：**总分 ≥ 32（64%）且无任何一维 ≤ 3** 才过门。低于门槛 → 回炉改最弱一维，不落位。

## 独立复评（反同源）

- 候选技能的作者与评分者**不得是同一上下文**：派 SubAgent 以"纯读者"视角加载技能正文并按五维打分，附证据
- 作者自评仅用于预筛（自查项），过门判定以 SubAgent 评分为准
- 同源评分一旦发现（未派 SubAgent 就宣布过门），本轮质量门作废重跑

## 棘轮回滚

- 新稿评分 > 旧版评分 → 落位
- 新稿 ≤ 旧版 → 丢弃新稿，保留旧版，把被拒方案、目标维度与拒绝理由追加到该技能 `notes/` 进化履历
- 被拒记录是复盘旁证资产：下次优化同一技能时先读它，避免重复走进死路

## 体积控制（fapprox 先验）

行数检查之外，跑 `scripts/fapprox.py` 取每条记忆的 F_approx 引用密度：P0 未引用 → 建议删除；P1 可精简 → 提取引用段后删原文件；P2 暂不处理；P3 核心资产 → 保留。精简动作仍需用户确认（破坏性操作）。

## 规则硬化（HASP 精魄）

技能执行中同一规则被连续忽略时，按违规次数自适应强化：

| 违规次数 | 动作 |
|---|---|
| 1 次 | 不处理 |
| 2 次 | 措辞强化：Should → Must（"建议 X"改"强制：必须 X，超限必须拆分"） |
| ≥3 次 | 升格为可执行触发+干预：定义触发条件（何时激活）与干预动作（违反时阻断/重定向） |

**硬化适用性**：输出格式、文件大小、必备章节等可精确检测的约束适合硬化；语义风格、创造性建议**不适合**（无法形式化，硬了反而误伤）。

**软化词扫描**：跑 `scripts/softscan.py`，`soft_rules` 数组即待硬化规则清单（含行号与句式标签）。

## 编辑回归（MUSE 精魄）

对技能/记忆文件做任何修改前，先按六个维度生成 5-10 条测试用例并快照：

| 维度 | 生成方法 |
|---|---|
| 触发识别 | 提取触发词逐一构造输入，验证触发 |
| 输出格式 | 提取格式约束，构造验收条件 |
| 规则遵守 | 提取"必须/禁止"语句，构造边界测试 |
| 流程完整 | 按 Step 逐项模拟，断链测试 |
| 引用可达 | 遍历文件路径引用，逐条存在性检查 |
| 反例 | 构造明确不在范围内的输入，验证不触发 |

修改后跑回归：全部通过 → 收工并通过的用例沉淀累积（下次复用）；部分失败 → 列偏差建议回滚；全部失败 → 强制回滚。

## 收敛信号

- 单轮只改一个维度（相关维度联动时观察不并改）
- 连续 2 轮提升 < 1 分 → 停止，当前版本即为定稿
- 任何维度优化后 ≤ 3 分且无法再改 → 技能标记"待拆分"（可能一个技能想做所有事）

## 反模式

| # | 反模式 | 正确做法 |
|---|---|---|
| 1 | 同上下文自评自改 | 派 SubAgent 独立复评 |
| 2 | 为过门堆内容 | 体积维度本身扣分，先精简 |
| 3 | 轮内打包改多维度 | 一轮一维，可归因 |
| 4 | 静默忽略评分证据 | 每维附证据再给分 |
| 5 | 候选技能引用原始记忆 | 重写为自包含 |
