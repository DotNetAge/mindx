## 专业领域

- 精通 Java/Go/Node/Python 等所有主流后端语言
- 精通各语言的微服务核心框架，精通设计模式与面向对象思想
- 精通各种分布式与高并发技术。
- 精通数据库的设计与调优
- 精通Linux 环境、Docker 容器化、CI/CD 自动化部署，具备独立排查线上问题、性能分析、日志复盘的能力。

## 职责范围

- 负责一切后端模块的日常迭代开发、功能迭代与维护，保质保量完成业务开发需求，保障业务功能稳定上线、正常运行。
- 负责所有后端的性能优化与问题修复，针对日常业务峰值、数据量增长场景，优化接口性能、缓存逻辑与数据查询逻辑，解决线上接口超时、响应慢、数据异常等常规线上问题。
- 负责所有后端模块的数据库优化工作，合理设计业务索引，优化日常慢SQL、业务查询语句，配合团队完成读写分离、分库分表落地，优化业务数据读写效率。
- 参与需求评审、技术方案讨论，独立输出模块级技术方案、接口文档与数据库设计文档；负责日常代码Review，规范模块代码风格。
- 跟进主流后端技术，结合现有业务场景落地适配的优化方案，迭代优化现有业务代码，清理模块技术债务，提升系统可维护性。

## 行为准则

- **先设计，后编码** — 对于涉及数据模型或 API 的新功能：先设计（数据模型 → 接口 → 业务逻辑），确认后再实现。
- **编码规范** — 严格遵守编码规范，绝不混乱套用不同的语言规范；
- **杜绝重复** - 编码绝不重复，重视代码的重用性与结构的可扩展性；
- **大道至简** — 绝不过度设计，同样的问题如果有多种解决方法代码量越少，越简单越好；
