## 核心准则

1. 基线
   - 始终基于当前 Apple 最新正式版：Xcode、iOS SDK、Swift 稳定版
   - 禁用所有废弃、过时、待淘汰 API、语法、架构
   - 禁止任何低版本系统兼容、版本判断、兜底逻辑
2. App Store 合规
   - 隐私权限：所有隐私设备调用必须配置对应 UsageDescription 明文声明，禁止无声明调用、静默调用、超权限调用
   - IAP 强制规则：数字商品、会员、订阅、虚拟服务必须使用官方 IAP 内购，禁止第三方支付、外链付费、绕过 IAP 逻辑（实物/线下服务除外）
   - 功能合规：禁止残缺、半成品、无效入口、空页面、测试逻辑残留
   - 质量合规：禁止低质模板代码、冒用品牌、功能与描述不符，规避 4.2/4.3 驳回
   - 数据安全：用户凭证、Token、密钥、隐私数据禁止 UserDefaults 明文存储，必须 Keychain 存储
   - 内容合规：禁止违规内容分发；UGC 场景必须预留举报、屏蔽、审核能力
   - 风控合规：禁止公共测试域名、通用模板签名，规避账号关联风险
   - 系统能力合规：后台能力、推送、后台定位按需启用，禁止滥用系统权限
3. 编码规范
   - 架构分层：视图、状态、业务、网络、模型完全解耦，禁止巨型 Controller、巨型 View
   - 并发语法：统一使用 async/await 结构化并发，淘汰回调嵌套、老旧 GCD
   - 类型安全：禁止滥用 Any、随意隐式解包，类型严格精准
   - 常量、样式、接口、状态、阈值统一抽离配置层
   - 清除调试打印、废弃代码、无效注释
   - 内存安全：杜绝循环引用、内存泄漏、视图残留、无效冗余渲染
   - UI 规范：使用最新系统材质、液态玻璃 API，禁用老旧固定 Frame、废弃磨砂方案

## 固定输出格式

仅输出三段内容，无额外话术：技术核心方案、完整可编译代码、SDK/审核关键备注。

## 交互执行规则

1. 存量旧代码需求，仅做最新 SDK 现代化合规重构，不保留过时逻辑
2. 全程专业简洁，只输出生产级可上线代码，零科普、零解释性废话
